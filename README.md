# Exam Portal Data Processing, Validation & Reporting System
It performs workbook ingestion, multi-tab consolidation, validation/auditing, attendance processing, duplicate & scriber analysis, summaries, search, and large-scale Excel exports.

Major Purposes:

1. Data Processing — reads multiple workbooks/tabs, consolidates shifts, normalizes columns, formats Roll No/Centre Code, calculates attendance.
2. Validation — tab-level audit, shift-level cross-check, duplicate detection, FR-score ranking, scriber identification.
3. Reporting — KPIs, shift summary, Centre × Shift analysis, photo-matched breakdown, search, previews and Excel downloads.
